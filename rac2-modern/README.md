# RAC-2Modern

A modern look for *Ratchet & Clank: Going Commando* (*Locked and Loaded*) in OpenRAC's native port,
one planet at a time. It starts with Aranos (level 0) and Oozla (level 1) on the European disc.

**0.1.0 is the foundation.** The mod installs, loads and writes a line in the game's log. It does
not change anything on screen yet.

Use it with OpenRAC's **Enhanced graphics** on (**Mods** → **My mods**).

Source, roadmap and rules: <https://github.com/dakajod-lab/RAC-2Modern>

RAC-2Modern is an unofficial fan project. It is not affiliated with Sony Interactive Entertainment
or Insomniac Games.
